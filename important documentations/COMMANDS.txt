================================================================================
 AEGIS SCANNER — COMMAND REFERENCE
 Cyber404 Academy 2026
================================================================================
Run everything from the repo root (aegis-scanner/). All relative paths
(output/, database/aegis.db, .env) resolve from there.

LEGAL: only run this against targets you own or have explicit written authorization
to test -- this now includes sqlmap (SQL injection probing, plus read-only DB
metadata enumeration on a confirmed injection), the nuclei DAST XSS pass (which
actively injects payloads into query parameters), hydra (credential brute-forcing),
and wpscan/enum4linux. All of these are more intrusive than the original
recon/scan/audit toolset and can trip IDS/WAF alerts or lock out accounts.


--------------------------------------------------------------------------------
 1. INSTALL / SETUP
--------------------------------------------------------------------------------

  git clone https://github.com/syedj-hacks/aegis-scanner.git
  cd aegis-scanner
  chmod +x install.sh
  ./install.sh
  source venv/bin/activate

  # install.sh does, in order:
  #   1. apt install bind9-dnsutils nmap nikto gobuster subfinder amass theharvester dirb
  #                   whatweb nuclei zaproxy sslyze wpscan sqlmap hydra enum4linux
  #   2. apt install python3-venv python3-pip libpango-1.0-0 libpangocairo-1.0-0
  #                   libcairo2 libgdk-pixbuf-2.0-0   (WeasyPrint's native PDF libs)
  #   3. python3 -m venv venv
  #   4. pip install -r requirements.txt
  #   5. python3 setup.py   (checks deps, creates output/ + database/, copies
  #                           config.example.py -> config.py automatically, offers an
  #                           optional personal AEGIS_NVD_API_KEY prompt written to .env
  #                           -- a shared default key already ships in config.example.py,
  #                           so this step can be skipped safely)

  # Re-run setup only (skip apt/venv, e.g. after editing .env by hand):
  python3 setup.py

  # Manual config template copy (setup.py now does this automatically on first run --
  # only needed if you deleted modules/utils/config.py and want to recreate it by hand;
  # it's gitignored on purpose):
  cp modules/utils/config.example.py modules/utils/config.py

  # ZAP note: modules/web/zap_wrap.py drives ZAP's own daemon over its REST API
  # (via the python-owasp-zap-v2.4 client in requirements.txt), not a bundled
  # zap-baseline.py script -- apt's zaproxy package doesn't ship one anyway. You
  # need a JRE and zap.sh on this host (both covered by install.sh's apt step);
  # if either is missing, ZAP is reported unavailable rather than the scan failing.
  # install.sh ALSO bootstraps ZAP's passive-scan-rules add-on (pscanrules) once,
  # on a fresh ~/.ZAP -- without it ZAP scans complete cleanly and return 0
  # findings forever. If ZAP findings ever drop to zero after previously working,
  # do NOT run `zap.sh -addonupdate` / `-addoninstall <id>` to fix it (that
  # sequence is the leading suspect for how the add-on gets uninstalled): back up
  # and delete ~/.ZAP, then re-run install.sh.

  # venv note: run Aegis through the SAME interpreter you installed into.
  #   venv/bin/python aegis.py <target> --profile <profile>
  # A venv missing one dependency is invisible until a scan reports "tools
  # failed: 1" -- exactly what happened when venv/ lacked the ZAP client while
  # the system Python had it. `python3 setup.py` verifies every REQUIRED_MODULES
  # entry (rich, requests, scapy, weasyprint, zapv2) actually imports.

  # nuclei note: if apt's nuclei package is missing/stale on your mirror, install.sh
  # falls back to `go install` automatically (requires a Go toolchain on PATH).


--------------------------------------------------------------------------------
 2. RUNNING A SCAN (main entry point)
--------------------------------------------------------------------------------

  python3 aegis.py [target] [--profile PROFILE] [-v | --verbose] [--non-interactive]
                   [--version] [-h | --help]

  # target        hostname or IP address (validated before anything runs); now OPTIONAL --
  #               omit it entirely and you'll be interactively prompted for one, then for
  #               a profile from a numbered menu (defaults to quickscan on empty input)
  # --profile     quickscan (default) | stealthscan | webaudit | deepscan | compliance
  #               omitting this with a target given still silently defaults to quickscan
  #               (unchanged behavior); the profile menu only appears in interactive mode
  # -v/--verbose  prints the resolved tool list + nmap_args for the chosen profile
  # --non-interactive
  #               never prompt: when the stored-report cap (5 per profile+target) is hit,
  #               delete the oldest report automatically instead of asking. IMPLIED
  #               whenever stdin/stdout is not a terminal, so piped/cron runs get it free
  # --version     prints "Aegis Scanner 1.0.0" and exits
  # -h/--help     full usage + profile table

Examples:

  python3 aegis.py 192.168.56.101 --profile deepscan
  python3 aegis.py scanme.nmap.org --profile quickscan
  python3 aegis.py example.com --profile webaudit -v
  python3 aegis.py 10.0.0.5 --profile stealthscan
  python3 aegis.py example.com --profile compliance
  python3 aegis.py                                      # interactive: prompts for target + profile
  venv/bin/python aegis.py example.com --profile deepscan --non-interactive   # scripted run

  # While a scan is running (interactive terminal only):
  #   s          skip just the tool currently running, move to the next one
  #              (ignored for nmap/DNS resolution -- everything downstream needs them)
  #   Ctrl+C     same as 's' on a single press; a SECOND Ctrl+C within ~2s aborts
  #              the whole scan instead

 4. INDIVIDUAL MODULE TESTING (import + call from a Python shell / script;
    every module function returns a dict and never raises)
--------------------------------------------------------------------------------

  python3 -c "from modules.scanning.service_detect import detect_services; print(detect_services('scanme.nmap.org', [22, 80]))"
  # now runs nmap -sV -sC combined -- return dict also includes a 'scripts' key
  python3 -c "from modules.scanning.banner import grab_banners; print(grab_banners('scanme.nmap.org', [22, 80]))"
  python3 -c "from modules.scanning.enum4linux_wrap import run_enum4linux; print(run_enum4linux('scanme.nmap.org'))"
  python3 -c "from modules.scanning.hydra_wrap import run_hydra; print(run_hydra('scanme.nmap.org', 'ssh', port=22))"

  # Web
  python3 -c "from modules.web.header_check import check_headers; print(check_headers('example.com', port=80))"
  python3 -c "from modules.web.nikto_wrap import run_nikto; print(run_nikto('example.com', port=80))"
  python3 -c "from modules.web.gobuster_wrap import run_gobuster; print(run_gobuster('example.com', port=80))"
  python3 -c "from modules.web.dirb_wrap import run_dirb; print(run_dirb('example.com', port=80))"
  python3 -c "from modules.web.whatweb_wrap import run_whatweb; print(run_whatweb('example.com', port=80))"
  python3 -c "from modules.web.nuclei_wrap import run_nuclei; print(run_nuclei('example.com', port=80, severity=['critical','high']))"
  python3 -c "from modules.web.sslyze_wrap import run_sslyze; print(run_sslyze('example.com', port=443))"
  python3 -c "from modules.web.wpscan_wrap import run_wpscan; print(run_wpscan('example.com', port=80))"
  python3 -c "from modules.web.sqlmap_wrap import run_sqlmap; print(run_sqlmap('example.com', 'http://example.com/page.php?id=1'))"
  python3 -c "from modules.web.xss_wrap import run_xss; print(run_xss('example.com', 'http://example.com/search.php?q=1'))"
  # NOTE: sqlmap and xss both REQUIRE a URL with a query string and refuse one without
  # it -- nuclei's DAST XSS templates have nothing to mutate against a bare path, and a

  python3 -c "from modules.web.zap_wrap import run_zap_baseline; print(run_zap_baseline('example.com', port=80))"

  # Build the fuzzable URLs the XSS pass uses, from gobuster/dirb output:
  python3 -c "from modules.profiles._common import web_param_candidates; print(web_param_candidates({'discovered_paths':[{'path':'/search.php','status_code':200}],'base_url':'http://example.com'}, None))"

  python3 -c "from modules.enrichment.cve_lookup import lookup_cves_from_banner; print(lookup_cves_from_banner('Apache/2.4.7 (Ubuntu)'))"

  python3 -c "from modules.enrichment.remediation import get_remediation; print(get_remediation({'cve_id':'CVE-2021-1234'}))"

  # Reporting
  python3 -c "from modules.reporting.summary import build_summary; print(build_summary(1))"
  python3 -c "from modules.reporting.report_txt import generate_txt_report; print(generate_txt_report(1))"
  python3 -c "from modules.reporting.report_pdf import generate_pdf_report; print(generate_pdf_report(1))"

 5. DATABASE (SQLite at database/aegis.db)
--------------------------------------------------------------------------------

  # Open a shell on the scan database directly
  sqlite3 database/aegis.db

  # Three tables: scans, findings, scan_tools_run
  .tables
  .schema scans
  .schema findings
  .schema scan_tools_run
  SELECT * FROM scans ORDER BY timestamp DESC LIMIT 10;
  SELECT * FROM findings WHERE scan_id = 1;
  SELECT id, target, profile, timestamp FROM scans WHERE target = 'example.com';

  # Which tools actually ran on a scan, and how each one ended
  # (recorded from scan 147 onward; older scans have no rows and were NOT backfilled):
  SELECT tool_name, port, outcome FROM scan_tools_run WHERE scan_id = 150;
  SELECT outcome, COUNT(*) FROM scan_tools_run WHERE scan_id = 150 GROUP BY outcome;

  # The injection evidence columns (NULL on every non-injection finding):
  SELECT port, finding_type, parameter, payload, endpoint FROM findings
    WHERE finding_type IN ('sqlmap_finding','xss_finding');

  # From Python instead of the sqlite3 CLI:
  python3 -c "from database.db import get_scan_history; print(get_scan_history())"
  python3 -c "from database.db import get_scan_history; print(get_scan_history('example.com'))"
  python3 -c "from database.db import get_findings_for_scan; print(get_findings_for_scan(1))"
  python3 -c "from database.db import get_scan_tools_run; print(get_scan_tools_run(150))"
  python3 -c "from database.db import get_latest_scan; print(get_latest_scan('example.com'))"
  python3 -c "from database.db import init_db; init_db()"   # re-create tables if missing


--------------------------------------------------------------------------------
 6. LOGS & OUTPUT
--------------------------------------------------------------------------------

  # Every target gets its own output directory:
  #   output/<target>/scan_errors.log
  #   output/<target>/report_<profile>_<target>_<scan_id>.txt
  #   output/<target>/report_<profile>_<target>_<scan_id>.pdf
  #
  # ALL FIVE profiles now write both a .txt and a .pdf (not deepscan only), and both
  # are named per scan so a new scan never overwrites an older report. The exact paths
  # are printed in the REPORT GENERATED block at the end of every run.
  #
  # History is capped at 5 reports PER PROFILE+TARGET (the .txt and .pdf of one scan
  # count as one unit). Interactive runs are asked which to drop; --non-interactive
  # runs drop the oldest and log it.

  tail -f output/<target>/scan_errors.log         # watch a scan's errors live
  ls -t  output/<target>/report_*.txt             # newest report first
  cat    output/<target>/report_quickscan_<target>_<scan_id>.txt
  xdg-open output/<target>/report_deepscan_<target>_<scan_id>.pdf

  # .env at repo root (gitignored) — only real secret is the NVD API key:

  # A real shell export always overrides .env:
  export AEGIS_NVD_API_KEY=<your-key-here>
